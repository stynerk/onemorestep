# 미리내 MVP에서 보여 줄 것 (v0.2)

작성: PM 소라, 2026-11-13. v0.2에서 HJ의 흐름을 기준으로 삼았다. HJ 요청으로 소라의 [AGENT.md](AGENT.md)와 Cap의 의견(2026-11-13 Discord)을 하나로 합쳤다. 상태: 관문 2(데모 시나리오) 후보안, HJ 확인 전.

## 한 줄

대표의 회사 맥락을 바탕으로 외부 변화를 먼저 살피고, "왜 우리에게 중요한지"와 "지금 할 일"까지 준비해 주는 에이전트.

MVP가 증명할 것 하나(Cap): **이 제안 덕분에 대표가 유용한 행동을 하나라도 시작했는가.**

## v0.2: HJ가 생각한 흐름 (2026-11-13, 기준)

HJ 설명과 HJ의 이전 와이어프레임("귀띔", claude.ai 디자인 캔버스)을 참고해 흐름을 다섯 단계로 고정한다. 아래 장면 표는 이 흐름에 맞춰 고쳤다.

```text
① 회사 정보 세팅      시작 질문 (+ 기존 자료 붙여넣기)
② 월드 모델 구성      미리내가 회사와 주변(시장·경쟁사 / 지원 제도 / 단계별로 챙길 일)을 한 장으로 그려 보여 주고, 대표가 직접 고친다
③ 내 업무 제안        지금 직무(대표)에서 할 만한 일을 카드로 제안: 무엇을 · 왜 지금 · 근거 · 첫 행동
④ 업무 지도 펼치기    고른 일을 단계별 지도로 펼친다 (예: 지원사업 신청 = 공고 확인 → 자격 대조 → 사업계획서 → 증빙 서류 → 제출)
⑤ 체크리스트 추적     단계마다 체크리스트로 진행을 기록하고, 막힌 단계는 다음 제안에 반영
확장                  직무만 바꾼다: 마케터, 개발자, PM, 디자이너. 월드 모델과 업무 지도 틀은 그대로, 직무별 관심 대상과 지도 템플릿만 다르다
```

귀띔에서 가져올 것:
- 월드 모델 화면은 "모든 제안의 기준점"이다. 대표가 직접 고칠 수 있어야 믿는다. 저장하지 않는 정보는 화면에 밝힌다.
- 제안 카드는 무엇을 · 왜 지금 · 근거(출처 2곳 이상) · 20분 안에 할 첫 행동.
- 제안 유형 표시: 놓치는 일 / 모르는 일 / 계획의 빈칸. "계획의 빈칸"(외부 흐름이 내 계획의 빈 곳과 겹침)이 미리내만 할 수 있는 제안이라 강조한다.
- MVP는 직무 하나(대표)만 열고, 다른 직무는 잠긴 채로 보여 확장성을 드러낸다.

귀띔에서 미루는 것: 노션·드라이브 연동 가져오기(MVP는 붙여넣기만), 주간 체크인(로드맵).

## 두 의견에서 합친 것

| 주제 | 소라 | Cap | 합친 안 |
|---|---|---|---|
| 회사 모델 | 질문 6개, 되묻기로 보충 | 시작 질문 → 첫 제안 후 보충 → 사용 중 갱신. 항목마다 사실/가설, 입력 시각 표시 | 시작 질문 6개 + 되묻기 + 사실/가설 표시 |
| 시작 질문 | 소개, 고객, 단계·등록, 지역·대표 조건, 3개월 목표, 경쟁사 | 소개, 단계, 이번 달 목표, 가장 큰 고민, 제약 | 아래 6개. 지역·대표 조건은 되묻기로 받는다(되묻기 장면을 보여 주는 재료) |
| 테마 | 시장·경쟁사 / 스타트업 지원 / 우리 회사에 필요한 것 | 같은 맥락을 나눠 보여 주는 분류일 뿐, 별도 에이전트 아님 | 같음 |
| 판단 | 누가 쓰나 결정 필요 | 규칙 + LLM 조합 안, 모델 미정 | 결정 필요(아래) |
| 근거 | 날짜·금액·자격은 원문 출처와 함께만 | 출처, 연결된 회사 정보, 불확실한 부분 표시. 근거 부족하면 "확인 필요" | 같음. 카드마다 "회사 정보 중 무엇과 연결됐나"를 보인다 |
| 실행 준비 | 할 일 한 줄, 체크리스트 | 조건 대조, 준비 목록, 질문·소개 자료 초안 | 체크리스트 + 초안 하나 |
| 실행 시점 | 매일 아침(데모는 버튼) | 홈 진입·새로고침·정시 중 정해야 함 | MVP는 "지금 찾기" 버튼. 정시 실행은 로드맵 |
| 평가 | 행동 전환, 관련성, 새로움, 신뢰, 인터뷰 | 정보 품질 → 판단 품질 → 행동 변화. 일반 소식 목록과 비교 | 합쳐서 아래 표 |
| 출발점 | 페르소나 A 주 대상 | "어떤 회사의 어떤 판단 하나"부터 정하자 | 가상 회사 하나, 판단 하나로 데모를 만든다 |

## 시작 질문 6개

1. 무슨 사업인가요? (누구의 어떤 문제를)
2. 지금 어디까지 왔나요? (단계, 사업자 등록 여부)
3. 이번 달 가장 이루고 싶은 것은?
4. 지금 결정하지 못하고 있는 것은?
5. 직접 할 수 있는 일과 도움이 필요한 일은? (자원·제약)
6. 지켜볼 경쟁사나 비슷한 서비스는?

답마다 "확인된 사실 / 아직 추측"을 고를 수 있다.

## 데모 회사와 판단 하나 (제안, 가상)

- 회사: 예비창업 1인 대표, AI로 소상공인 업무 자동화. 시제품 있음, 테스트 고객 없음. 사업자 등록 전.
- 이번 달 목표: 초기 자금 확보(지원사업 신청).
- 고민: 사업자 등록을 언제 할지. 영업 경험이 적다.
- 경쟁사: △△사.
- 미리내가 돕는 판단: **"이번 달 어떤 지원사업에, 언제까지, 무엇을 준비해 신청할까"**

## 데모에서 보여 줄 장면 (영상 5분 기준)

| # | 장면 | 보여 주는 차별점 | 시간 |
|---|---|---|---|
| 1 | ① 시작 질문 6개에 답한다. 한 답에 "아직 추측" 표시 | 회사 맥락, 사실/가설 구분 | 35초 |
| 2 | ② Liner로 주변을 찾아 월드 모델 한 장을 그린다(회사 · 시장·경쟁사 · 지원 제도 · 단계별 할 일). 대표가 한 곳을 고친다 | Liner 활용, 내 회사 기준, 고칠 수 있음 | 50초 |
| 3 | ③ 오늘의 제안 3건. 유형(놓치는 일 / 모르는 일 / 계획의 빈칸) 표시 | 묻기 전에 제안, 알림이 아니라 할 일 | 35초 |
| 4 | 제안 상세: 무엇을 · 왜 지금 · 근거(원문 출처) · 20분 첫 행동, 자격 대조(✔ / 확인 필요) | 근거 | 50초 |
| 5 | 되묻기: "이 공고는 서울 소재만 가능해요. 서울에 계신가요?" → 월드 모델 갱신 → 판단 변화 | 쓰면서 자란다 | 30초 |
| 6 | ④⑤ "이 일 하기" → 업무 지도 펼치기(지원사업 신청 5단계) → 단계별 체크리스트, 진행률 | 행동까지 이어지고 추적됨 | 50초 |
| 7 | 직무 전환 메뉴: 대표(열림) / 마케터·개발자·PM·디자이너(잠김). 같은 틀로 넓어진다 | 확장성 | 20초 |

화면: PC 웹 중심으로 녹화, 모바일은 한 장면(반응형)만.

## MVP에서 보여 주지 않는 것

정시 자동 실행, 로그인, 실제 캘린더·메일 연동, 지원사업 사이트 크롤링, 문서·노트 연결로 지식 쌓기, 반응 기반 개인화 학습, 외부 신청·연락. 모두 기획서 확장성 장에 둔다.

## 평가 (출시 전 → 테스터)

| 단계 | 무엇을 | 어떻게 |
|---|---|---|
| 정보 품질 | 날짜·조건·주장이 원문과 맞나, 지난 공고 0건 | 카드 표본을 원문과 대조(소라) |
| 판단 품질 | 관련 있나, 새로운가, 바로 시작할 수 있나 | 페르소나 3개의 가상 시나리오로 누락·오추천 검사, 카드마다 "몰랐어요/알고 있었어요" |
| 행동 변화 | 준비 시작·초안 수정 등 실제 행동 | 테스터에게 같은 정보를 "일반 소식 목록"과 "미리내"로 보여 주고 판단 시간과 행동 비교 |
| 대회 | 배점 4항목 | Gemini 심사위원 채점 |

페르소나 시나리오 통과와 실제 사용자 검증은 나눠 기록한다. 목표치는 테스터 확정 후 정한다.
