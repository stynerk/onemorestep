# 미리내 기획서 (초안 v0.2)

작성: PM 소라, 2026-11-12. 상태: 초안. `[HJ]` 표시는 HJ의 확인이나 입력이 필요한 곳이다.

배점: 문제 정의 30, 완성도 30, Liner API 활용 20, 확장성과 임팩트 20.

v0.2 변경: HJ 방향(2026-11-12)과 아이디어 제공자의 피드백을 반영했다. 마감 챙기기는 기본 기능이고, 중심은 "내 사업에 맞는 기회와 흐름을 먼저 알려 주는 것"이다.

## 1. 문제 정의 (30점)

- 한 줄: 창업을 준비하거나 작은 사업을 하는 사람은 내 사업에 맞는 지원사업, 펀딩, 기술 흐름을 매일 찾아볼 여유가 없다. 알았을 때는 이미 마감이 지났거나 남보다 늦다.
- 지금의 도구로 안 되는 이유: 뉴스레터와 검색은 내 상황을 모른다. 같은 글을 반복하고 이론 위주이며, "그래서 내가 뭘 해야 하는지"를 말해 주지 않는다(아이디어 제공자 피드백, 2026-10-30 대화).
- 아이디어 제공자의 말(요지): "내가 놓치거나 하면 좋은 일, 요즘 대세가 이건데 너 이런 거 해야 해 같은 것", "에이전트를 어떻게 활용할지 고민하는 것보다 더 나은 걸 해 주길 기대한다".
- HJ의 일화(가설, 사실 확인 전): HJ가 그려 본 이야기다. 트렌드 워치 뉴스레터로는 알려 주기만 할 뿐 행동으로 이어지지 않는다. 확인된 사실은 HJ가 에이전트 뉴스레터를 보냈고, 독자인 아이디어 제공자가 "출처가 제한적이고 이론적"이라고 피드백했다는 것까지다(2026-10-30 대화). 제출물에는 사실로 확인된 부분만 쓴다.
- 그래서 미리내는 "알림"이 아니라 "행동"까지 간다. 카드마다 내가 할 일 한 문장과 시작에 필요한 준비물(체크리스트, 초안 자료)을 함께 낸다.
- 근거 보강: 2026-11-13 아이디어 제공자 인터뷰. 실제로 놓친 지원사업이나 트렌드 사례를 받는다.

## 2. 대상 사용자

- 주 대상: 초기 창업자와 창업 준비자. 혼자 또는 작은 팀으로 일하고, 지원사업·투자·기술 변화가 사업에 직접 영향을 준다.
- 테스터: 아이디어 제공자. 2주 참여 여부는 인터뷰에서 확인한다.

## 3. 핵심 시나리오 (데모 후보, 관문 2)

1. 사용자가 사업 프로필을 적는다: 하는 일, 단계(예: 예비창업, 시드), 관심 기술, 지역. 일정과 할 일도 넣는다(데모는 가상 데이터).
2. 사용자가 묻지 않아도 미리내가 오늘의 "미리 챙길 일" 카드 3장을 낸다. 카드마다 왜 나에게 해당하는지, 무엇을 언제까지 하면 되는지, 출처를 보여 준다.
   - 기회: "예비창업자 대상 ○○ 지원사업 공고가 났어요. 마감 11월 28일. 신청서에 필요한 사업계획서 항목을 정리해 뒀어요" (Liner 검색, 공고 원문 출처)
   - 흐름: "에이전트 업계에서 ○○ 방식이 빠르게 퍼지고 있어요. 지금 제품에 적용할 지점 2가지를 정리했어요" (Liner 검색, 실무자 글·저장소·커뮤니티 등 여러 출처)
   - 마감: "금요일 IR 자료 마감인데 시장 규모 자료가 아직 없어요. 근거 자료 3건을 모아 뒀어요"
3. 사용자는 카드마다 "했어요 / 나중에 / 필요 없어요"를 누른다. 미리내는 카드 상태를 저장해 처리한 카드를 다시 내지 않는다. 반응으로 다음 제안을 고치는 개인화 학습은 로드맵이다(PR #5, PM 결정).

## 4. MVP 범위

| 포함 | 근거 |
|---|---|
| 사업 프로필, 가상 일정·할 일 입력 | 내 상황을 알아야 "나에게 맞는" 제안이 된다 |
| 카드 3종(기회, 흐름, 마감) 하루 3장 | 데모의 중심 장면. HJ가 정한 방향 |
| 카드별 Liner 검색 결과와 출처, 원문 링크 | Liner API 활용 20점. 출처의 다양성과 실전성이 품질 기준 |
| 카드 반응 버튼과 상태 저장 | 완성도 |

| 제외 | 근거 |
|---|---|
| 실제 캘린더·메일 연동(OAuth) | 공수 대비 데모 가치 낮음. 로드맵 |
| 지원사업 사이트 크롤링, 정부 API 직접 연동 | Liner 검색으로 찾고 원문 링크로 확인하게 한다. 로드맵 |
| 알림 푸시, 모바일 앱, 로그인 | 핵심 가설과 무관 |

공수는 Cap의 추정을 받은 뒤 이 표를 줄여 맞춘다.

## 5. 품질 기준

- 카드의 날짜, 금액, 자격 조건은 반드시 원문 출처와 함께 보여 준다. 출처가 없으면 카드를 내지 않는다.
- 같은 출처를 반복하지 않는다. 카드 하나에 서로 다른 출처 2건 이상(가정, 인터뷰 후 조정).
- "무엇을 해야 하는지" 한 문장이 없는 카드는 내지 않는다.

## 6. 성공 지표 (가정)

- 데모: 프로필 입력부터 카드 3장까지 끊김 없이 1분 안에 보여 준다.
- 테스터: 카드 중 "했어요" 비율, "몰랐던 걸 알게 됐다"는 응답 수. 목표치는 테스터 확정 후 정한다.
