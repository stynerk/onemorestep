결정 필요 — 4단계를 누가 하나? Liner API는 검색 결과(출처)를 준다. "왜 나에게 해당하는지"와 "할 일 한 줄"을 쓰려면 글을 읽고 판단하는 단계가 필요하다.
① 규칙과 템플릿만: 비용 0, 결과가 딱딱하고 카드 종류가 좁다.
② LLM API 추가: 카드 품질이 가장 좋다. 별도 키와 비용이 생기고 심사 환경에서도 그 키가 필요하다 → HJ 관문.
③ Liner 플랫폼에 요약·답변 기능이 있으면 그것을 쓴다: Liner 활용 점수에도 유리. Cap 확인 필요.
추천: ③을 먼저 확인하고, 없으면 ②를 HJ에게 비용과 함께 올린다. ①은 키가 없을 때의 대체 경로로 둔다.
