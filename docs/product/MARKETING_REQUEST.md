# 마케팅 협조 요청 — 우선순위 배정과 채널별 콘텐츠 초안 (기획)

작성: 서비스PM Tony, 2026-11-23. 상태: HJ 확정(2026-11-23). 1차 구현 완료(#102, PR #104). **2차(접수·처리 흐름·효과 트래킹)는 아래 "2차" 절, Issue #107.**

## 문제

본사 세일즈 담당자들이 마케팅에 자료·홍보를 요청하지만, 마케팅은 어느 요청이 매출에 더 급한지 알 수 없어 먼저 온 순서나 목소리 큰 순서로 처리한다. 채널마다 문구를 새로 쓰느라 시간이 든다. 팀 대표(HJ)가 제조사에서 겪은 업무다(내부 수치 없음).

## 원칙

리드 판정과 같다. **AI가 준비하고 근거를 붙이고, 사람(마케팅 실무자)이 승인하거나 고치고, 그 결과가 기록으로 남는다.**

## 흐름

1. **요청 접수 (본사 세일즈만):** 요청자, 요청 주제, 연결된 리드·딜(단계·규모), 지역, 마감일, 메모. 딜러는 요청하지 않는다.
2. **우선순위 배정 (AI 점수 + 이유):** 아래 점수로 순서를 정하고 항목별 이유를 보인다. 같은 주제의 90일 내 요청은 "반복 요청"으로 표시하고 묶을지 제안한다.
3. **채널별 콘텐츠 초안:** 미리내가 채널을 추천하고(요청마다 전부가 아님), 채널별 초안을 만든다. 마케팅이 채널을 켜고 끌 수 있다.
4. **마케팅 검토:** 실무자가 순서를 조정할 수 있다(사유 필수, AI 점수와 사람 순위를 함께 기록). 초안은 승인·수정·반려한다. 실제 게시·발송은 하지 않는다(초안까지).

## 우선순위 점수 (0~100)

| 항목 | 가중치 | 값 (0~1) |
|---|---|---|
| 딜 규모·단계 | 40% | (단계 + 규모) / 2. 단계: 없음 0, 문의 0.3, 견적 0.6, 입찰·협상 1.0. 규모: 없음 0, 소 0.3, 중 0.6, 대 1.0 |
| 마감일 | 30% | 7일 이내 1.0, 14일 이내 0.7, 30일 이내 0.4, 그 뒤·없음 0.1 |
| 지역 전략 | 20% | 권역 가중치(**가정**, 정책 파일): APAC 1.0, EU 0.8, NA 0.8, 전 지역 0.8, LATAM 0.5, MEA 0.5 |
| 반복 요청 | 10% | 같은 주제 90일 내 다른 요청 0건 0, 1건 0.5, 2건 이상 1.0 |

가중치와 표 값은 정책 파일 하나에 둔다(리드 판정의 `policy.ts`와 같은 방식). 실무자 조정은 점수를 바꾸지 않고 순위만 바꾸며 기록에 남는다.

## 채널과 초안 규칙

| 채널 | 초안 형식 |
|---|---|
| 이메일 (마케팅 수신 동의자 대상) | 제목 + 본문 5~8줄 + 행동 유도 1개. 수신 동의 목록 대상이라는 표시. 발송하지 않음 |
| LinkedIn | 1,300자 이내, 전문가 어조, 해시태그 3개 이내 |
| Facebook | 3~4문장 + 링크 자리 |
| Instagram | 캡션 2,200자 이내 + 이미지 문구 제안 1줄 + 해시태그 5개 이내 |
| 블로그 | 제목 + 소제목 3개 개요 + 도입 단락 |

- 생성은 Liner Router, 사실 근거는 Liner Search(공개 자료). 근거 링크를 초안에 붙인다.
- **의료기기 문구 안전장치:** 효능·안전성을 단정하는 표현, 근거 없는 수치, 비교 우위 단정은 표시하고 실무자 확인을 요구한다. 근거 링크가 없는 사실 문장은 "확인 필요"로 표시한다.
- 실패하면 채널별 기본 틀(빈 양식)을 보이고 화면은 멈추지 않는다. 공개 시연은 기록 재생이다.

## 성공 기준 (시연)

- 8건의 순서가 위 예상 점수 순서와 같다(정책값 그대로일 때).
- 실무자 조정이 사유와 함께 기록되고 새로고침 뒤에도 남는다.
- 초안에 근거 링크가 있고, 단정 표현 경고가 최소 1건 보인다.
- 리드 판정 시연(저장 30/30, 메일 403)은 그대로다.

## 제외

딜러 요청, 실제 게시·발송, 이미지 생성, 성과(클릭·전환) 측정, 예산 배분.

# 2차: 요청 접수 → 처리 흐름 → 효과 트래킹 (HJ 확정 2026-11-23, Issue #107)

목표: 세일즈가 요청하고, 마케팅이 처리해 완료하고, **그 콘텐츠로 실제 들어온 리드의 품질**로 효과를 판단해 다음 채널 선택에 쓰는 흐름을 화면에서 닫는다. HJ: "마케팅의 목표는 세일즈를 위한 양질의 리드를 모으는 것"이므로 효과는 세일즈의 주관 평가가 아니라 **미리내가 판정한 유입 리드**로 잰다.

## (가) 요청 접수 (본사 세일즈)

- 입력: 요청자(가상 본사 세일즈 3명 중 선택), 요청 유형(사례 자료 / 전시회·행사 / 신제품 소개 / 캠페인 / 블로그·콘텐츠), 상품, 지역, 마감일, 딜 규모(소·중·대·없음), 메모. 연결 리드(선택).
- **연결 리드를 고르면 문의함 기록에서 자동으로 채운다:** 지역(리드 국가 → 권역), 딜 단계(유효·결정 대기 = 문의, 딜러 배정 = 견적, 그 밖 = 없음). 자동으로 채운 칸은 "문의함 기록" 표시.
- 접수하면 1차와 같은 정책 파일로 점수를 계산해 목록에 넣는다. **반복 요청:** 90일 안에 같은 상품·같은 유형 요청이 있으면 반복으로 표시하고 묶기를 제안한다.
- 필수값이 비면 접수 버튼을 잠근다.

## (나) 처리 흐름 (마케팅)

- 상태: **접수 → 진행(담당자 지정) → 검토(초안 승인 대기) → 완료**, 또는 **반려(사유 필수)**. 상태가 바뀔 때마다 시각과 담당자를 기록한다.
- 검토 → 완료는 초안이 하나 이상 승인돼 있어야 한다(1차의 "표현과 근거를 확인했습니다" 확인 포함).
- **마감 경고:** 마감 3일 이내인데 접수·진행 상태면 "마감 임박", 마감이 지났는데 완료가 아니면 "마감 초과". 목록 맨 위에 건수를 보인다.
- **요청자 보기:** 요청자별로 내 요청의 상태와 변경 기록을 본다(세일즈가 마케팅에 묻지 않아도 진행을 안다).
- **완료하면 캠페인 코드를 발급한다**(예: `C05`). 채널 게시물·이메일 링크에 붙일 유입 코드다. 이 코드로 들어온 리드를 다음 절에서 센다.

## (다) 효과 트래킹: 유입 리드의 품질

- 문의함 리드에 **유입 경로(캠페인 코드 또는 직접 유입)** 칸을 둔다. 리드 카드에도 "유입: C1 LinkedIn"처럼 보인다.
- 캠페인별로 **미리내 판정 결과**를 모아 보인다: 유입 리드 수, 유효·애매·국가 확인·제휴 확인·무효 수, **유효 비율**, 딜러에게 넘긴 수. 숫자는 사람이 입력하지 않고 문의함의 판정 기록에서 계산한다(문의함을 판정하지 않았으면 "판정 전"으로 보인다).
- **효과 판정(정책 파일):** 유입 3건 미만은 "판단 보류". 유효 비율 50% 이상 "효과 높음", 20% 이상 "보통", 20% 미만 "낮음". 리드 수가 많아도 유효가 적으면 낮음이다(양보다 질).
- **다음 판단에 반영:** 새 요청의 채널 추천 옆에 같은 채널의 지난 효과를 보인다(예: "LinkedIn · 효과 높음, 유효 3/5", "Instagram · 효과 낮음, 유효 0/6"). 효과 낮음 채널은 추천에서 빼지 않고 경고만 한다. 결정은 마케팅 실무자가 한다. 우선순위 점수 가중치는 바꾸지 않는다.

## 2차 성공 기준 (시연)

- 새 요청을 연결 리드로 접수하면 지역·단계가 자동으로 채워지고 점수 순위에 들어간다.
- 접수 → 진행 → 검토 → 완료가 기록되고, 완료 때 캠페인 코드가 나온다. 반려는 사유가 있어야 한다. 마감 임박·초과가 보인다.
- 캠페인 효과 표가 위 표와 같은 수치로 나온다(문의함 판정 결과에서 계산). 리드 카드에 유입 경로가 보인다.
- 리드 판정 시연(저장 30/30, SaaS 10/10, 메일 403)과 1차 마케팅 기능(8건 순서, 순위 조정, 초안)이 그대로다.

## 2차 제외

실제 UTM·광고 플랫폼 연동, 클릭·노출 지표, 수주 금액 귀속, 예산 배분, 우선순위 가중치 자동 학습.
