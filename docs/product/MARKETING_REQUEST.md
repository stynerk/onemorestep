# 마케팅 협조 요청 — 우선순위 배정과 채널별 콘텐츠 초안 (기획)

작성: 서비스PM Tony, 2026-11-23. 상태: HJ 확정(2026-11-23). 구현: Issue #102, 11-24 18:00까지 못 끝내면 기획서 설계로만 남긴다.

## 문제

본사 세일즈 담당자들이 마케팅에 자료·홍보를 요청하지만, 마케팅은 어느 요청이 매출에 더 급한지 알 수 없어 먼저 온 순서나 목소리 큰 순서로 처리한다. 채널마다 문구를 새로 쓰느라 시간이 든다. 팀 대표(HJ)가 제조사에서 겪은 업무다(내부 수치 없음).

## 원칙

리드 판정과 같다. **AI가 준비하고 근거를 붙이고, 사람(마케팅 실무자)이 승인하거나 고치고, 그 결과가 기록으로 남는다.**

## 흐름

1. **요청 접수 (본사 세일즈만):** 요청자, 요청 주제, 연결된 리드·딜(단계·규모), 지역, 마감일, 메모. 딜러는 요청하지 않는다.
2. **우선순위 배정 (AI 점수 + 이유):** 아래 점수로 순서를 정하고 항목별 이유를 보인다. 같은 주제의 90일 내 요청은 "반복 요청"으로 표시하고 묶을지 제안한다.
3. **채널별 콘텐츠 초안:** 미리내가 채널을 추천하고(요청마다 전부가 아님), 채널별 초안을 만든다. 마케팅이 채널을 켜고 끌 수 있다.
4. **마케팅 검토:** 실무자가 순서를 조정할 수 있다(사유 필수, AI 점수와 사람 순위를 함께 기록). 초안은 승인·수정·반려한다. 실제 게시·발송은 하지 않는다(초안까지).

## 우선순위 점수 (0~100)

| 항목 | 가중치 | 값 (0~1) |
|---|---|---|
| 딜 규모·단계 | 40% | (단계 + 규모) / 2. 단계: 없음 0, 문의 0.3, 견적 0.6, 입찰·협상 1.0. 규모: 없음 0, 소 0.3, 중 0.6, 대 1.0 |
| 마감일 | 30% | 7일 이내 1.0, 14일 이내 0.7, 30일 이내 0.4, 그 뒤·없음 0.1 |
| 지역 전략 | 20% | 권역 가중치(**가정**, 정책 파일): APAC 1.0, EU 0.8, NA 0.8, 전 지역 0.8, LATAM 0.5, MEA 0.5 |
| 반복 요청 | 10% | 같은 주제 90일 내 다른 요청 0건 0, 1건 0.5, 2건 이상 1.0 |

가중치와 표 값은 정책 파일 하나에 둔다(리드 판정의 `policy.ts`와 같은 방식). 실무자 조정은 점수를 바꾸지 않고 순위만 바꾸며 기록에 남는다.

## 채널과 초안 규칙

| 채널 | 초안 형식 |
|---|---|
| 이메일 (마케팅 수신 동의자 대상) | 제목 + 본문 5~8줄 + 행동 유도 1개. 수신 동의 목록 대상이라는 표시. 발송하지 않음 |
| LinkedIn | 1,300자 이내, 전문가 어조, 해시태그 3개 이내 |
| Facebook | 3~4문장 + 링크 자리 |
| Instagram | 캡션 2,200자 이내 + 이미지 문구 제안 1줄 + 해시태그 5개 이내 |
| 블로그 | 제목 + 소제목 3개 개요 + 도입 단락 |

- 생성은 Liner Router, 사실 근거는 Liner Search(공개 자료). 근거 링크를 초안에 붙인다.
- **의료기기 문구 안전장치:** 효능·안전성을 단정하는 표현, 근거 없는 수치, 비교 우위 단정은 표시하고 실무자 확인을 요구한다. 근거 링크가 없는 사실 문장은 "확인 필요"로 표시한다.
- 실패하면 채널별 기본 틀(빈 양식)을 보이고 화면은 멈추지 않는다. 공개 시연은 기록 재생이다.

## 성공 기준 (시연)

- 8건의 순서가 위 예상 점수 순서와 같다(정책값 그대로일 때).
- 실무자 조정이 사유와 함께 기록되고 새로고침 뒤에도 남는다.
- 초안에 근거 링크가 있고, 단정 표현 경고가 최소 1건 보인다.
- 리드 판정 시연(저장 30/30, 메일 403)은 그대로다.
