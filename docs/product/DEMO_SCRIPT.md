# 데모 영상 대본 — 미리내 (v0.2, 5분 이내)

작성: 서비스PM Tony, 2026-11-19. 상태: 7장면 HJ 확정(2026-11-19), 세부 대본 초안. 녹화·업로드는 HJ(SUBMISSION ②). 기준: `MVP.md` "데모 장면", `DEMO_DATA.md`. 내레이션은 자막.

v0.2: HJ 지시로 장면마다 **성공 케이스와 실패 케이스**를 짝지어 보인다. 실패 케이스는 두 종류다.
- **잡아낸 실패:** 리드나 딜러 쪽의 문제(사칭, 무효, 미응답, 딜러 없음)를 미리내가 걸러 내거나 막는 장면
- **미리내의 한계:** 미리내가 판단하지 않고 사람에게 넘기는 건(애매, 외부 확인 실패), 그리고 정답과 다르게 판정한 건

화면에 짝을 구분하는 표시: 성공은 초록 ✔, 실패·한계는 주황 ⚠ 자막 라벨.

- [ ] 장면 7 표는 앱 화면이 아니라 **영상 편집 표·자막**으로 넣는다(출처: `docs/qa/FINAL_EVALUATION_2026-11-20.md`). 공개 앱의 정답 대조 패널은 저장 30/30과 기준 변경 전 25/30·사례 L13·L05·L08을 보이므로 그 수치를 자막과 섞지 않는다

## 메모

- 숫자: "37%"는 HBR 2011 출처를 화면 하단에 작게 표기. "월 200건·80%"는 쓰면 "가정"을 함께 쓴다.
- 장면 7의 수치와 오답 사례는 #32 최종 평가(`FINAL_EVALUATION_2026-11-20.md`, PR #56·#58)에서 채웠다. 공개 앱 패널의 25/30은 넘길 곳 기준 변경 전 기록이라 자막에 쓰지 않는다.
- "외부 확인 실패"(장면 3)는 저장 결과에 그런 건이 없으면 빼고, 내레이션 한 문장만 남긴다.
- 장면 6은 재배정이 주 흐름이다(PR #42). 딜러 결과 직접 입력(deal/no deal)은 넣지 않는다.
