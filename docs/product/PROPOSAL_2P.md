## One More Step: 세일즈보다 한발 앞에서, 쏟아지는 리드 속 진짜 고객을 먼저 찾아 믿을 만한 딜러에게 바로 넘기는 세일즈 에이전트

### 1. 누가, 어떤 문제로, 얼마나 불편한가

**누가:** 딜러망으로 제품을 파는 제조사(예: 가상의 의료기기 제조사 Medicom)의 본사 세일즈 담당자. 리드마다 전화로 진짜 고객인지 확인하고 지역 딜러 한 곳에 넘긴다(팀 대표 HJ의 실무 흐름을 일반화).

| 소음이 신호를 묻는다 | 늦으면 기회가 사라진다 | 판단이 사람에게 묶여 있다 |
|---|---|---|
| **영업 전에 걸러진 리드 18.7~37.7%, 대기업 대상 71.2%** | **1시간 안에 연락하면 의사결정자와 대화할 가능성 약 7배** | **진짜 고객과 믿을 딜러를 개인 경험으로 판단** |
| B2B 폼 제출 100만 건 이상 분석(RevenueHero, 2025). 시나리오 가정: 월 약 200건 중 약 80%가 비적격 | 미국 기업 2,241곳 중 1시간 안에 답한 곳은 37%(Harvard Business Review, 2011) | 사람이 바뀌면 경험이 사라지고, 판단 기준도 사람마다 다르다 |

### 2. 해결 방식

담당자가 "선별 시작"을 누르면 One More Step이 **선별 → 넘길 곳·딜러 추천 → 결정 카드**를 준비하고 담당자는 승인만 한다.

```
리드 유입 → 선별(Liner로 기관·도메인·의도 확인) → 넘길 곳 → 딜러 추천(90일 결과로 순위) → 담당자 승인(근거 3개, 한 번에) → 결과 기록(↻ 다음 추천 반영)
```

| 유효 | 애매·국가 확인·제휴 확인 | 채용 문의 | 무효 |
|---|---|---|---|
| 국가 딜러 | 권역 세일즈팀(사칭 의심 포함) | 인사팀 | 이유 붙여 일괄 정리 |

선별 근거에는 링크와 검색 시각이 붙는다. 신규 딜러만 있으면 지역 담당자에게 먼저 확인하고, 결정 카드에서는 승인 외에 딜러 변경 / 전화 필요 / 무효 처리를 고를 수 있다. 메일은 테스트 수신함으로만 간다(공개 시연은 발송하지 않음).

- 국가 불일치와 제휴 제안에는 확인 메일을 만든다. 딜러가 기한을 넘기면 재배정을 제안하고 미응답 기록이 다음 딜러 순위를 바꾼다(**제조사만 가진 기록이 판단의 재료가 되는 반복 루프**).
- **전화 대상이 30건에서 최대 6건으로 준다(시연 30건 기준 건수, 작업 시간이 아님).** 무효 11건은 한 번에, 유효 8건은 승인 한 번, 국가 확인 3건·제휴 확인 2건은 확인 메일로 처리한다. 애매 6건도 화면 질문에 먼저 답하고 모르는 것만 전화하며, 확인된 답은 같은 기관의 다음 리드에 근거로 쓰인다. 지금은 거의 모든 리드에 전화한다(실무 경험, **가정**).

**블라인드 30건 결과 (2026-11-23):** 엔진 고정 후 세트를 열어 실무자 정답과 비교(실제 Liner 호출 84회: 검색 46, 모델 의도 29, 모델 도메인 판단 9). 선별 **17/30(57%)**, 넘길 곳 **21/30(70%)**. **유효를 무효로 버린 건 0건, 유효가 아닌 리드를 유효로 올린 건 0건**이고, 틀린 13건은 모두 "애매"로 사람에게 갔다. 한계: 정답 유효 11건 중 8건, 국가 확인 2건, 제휴 확인 3건이 애매로 갔다. 주원인은 사이트와 메일 도메인이 다를 때의 소유 확인(예: ucsf.edu와 ucsfhealth.org)과 소재지 특정이다.

**참고:** 시연 30건은 저장된 근거로 30/30(규칙과 함께 설계한 세트). 개발용 70건은 첫 블라인드 33/70(원본 정답 기준 23/70, 가상 기관 11건 정답 정정), 수정 후 재생 52/70이지만 결과를 본 뒤의 수치라 내세우지 않는다.

### 3. Liner API 활용

| 쓰는 곳 | API | 역할 |
|---|---|---|
| 소속 기관 조사 | Liner Search | "기관명 + 국가/업종" 검색으로 실재·소재지·공식 도메인 확인 |
| 사칭 걸러내기 | Liner Search 결과 | 공식 도메인과 메일 도메인을 대조해 닮은꼴을 사칭 의심으로 표시 |
| 문의 의도 판단 | Liner Router(모델) | 메모의 의도(구매·제휴·채용·과제·영업·스팸)를 고르고 근거 문장 인용 |
| 도메인 소유 판단 | Liner Router(모델) | 규칙이 확인 못 한 도메인만 검색 결과로 소유를 판단하고 원문·URL 인용 |
| 담당자 질문 | Liner Router(모델) | 애매 리드의 질문 문구 작성. 근거는 선별 기록에서 채우고 실패 시 기본 문구 |
| 마케팅 채널 초안 | Liner Router + Search | 채널별 초안과 근거 링크. 근거 없는 문장은 "확인 필요" 표시 |

- **AI가 판단하고 규칙이 지킨다.** 인용이 실제 메모·검색 결과에 있을 때만 모델 답을 쓰고, 모델 혼자 유효를 만들거나 가상 기관·사칭 의심·무료 메일 선별을 뒤집지 못한다. 실패하면 규칙으로 선별한다.
- **Liner가 빠지면 선별이 성립하지 않는다.** 소속을 공개 정보로 확인하지 못하면 "유효"를 주지 않는다. 검색 실패는 "외부 확인 실패"로 애매에 둔다.
- 실제 키로 기관 5곳 × 2질의 10회 모두 정상 응답, 네 항목(실재·업종·소재지·도메인) 모두 확인 3곳(2026-11-18).

### 4. 확장 가능성

**공통 원칙:** AI가 준비 → 근거를 붙임 → 사람은 승인만 → 결과가 다음 판단의 재료 ↻

| 딜러망을 가진 B2B 판매 전반 (구현) | 조직의 기억 | 같은 원칙의 다른 직무: 마케팅 협조 요청 (구현) |
|---|---|---|
| 산업재 총판·분석 장비·SaaS 리셀러에 같은 엔진을 쓰고 딜러 표와 정책값(집계 90일, 이력 기준 3건, 가중치, 나라→권역 매핑)만 바꾼다. 공개 시연에서 업종을 B2B SaaS(가상 회사 Flowline, 리셀러 파트너 7곳)로 바꿔 확인: 리드 10건 선별 10/10(개발 중 본 세트) | 결정과 딜러 결과가 기록으로 남아 다음 추천을 바꾸고, 신입 담당자도 같은 근거로 판단한다 | 요청에 딜 규모·단계(40), 마감일(30), 지역 전략(20), 반복 요청(10)으로 점수와 이유를 붙여 순서를 정하고, 채널(수신 동의 이메일·LinkedIn·Facebook·Instagram·블로그)을 추천해 Liner로 초안과 근거 링크를 만든다(발송·게시는 하지 않음). 효과는 캠페인 코드로 들어온 리드의 유효 비율로 잰다: 시연에서 Instagram 6건 중 유효 0건, LinkedIn 5건 중 3건. 목표는 양이 아니라 양질의 리드(시연 데이터·가중치는 가상·가정) |
