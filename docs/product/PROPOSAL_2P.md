## One More Step: 확실한 리드만 전달하는 세일즈 에이전트

수많은 리드와 문의들 속에서 가장 확실한 리드만 전달하는 세일즈 Agent

### 1. 누가, 어떤 문제로, 얼마나 불편한가

**세일즈 담당자는 문의마다 진짜 기관인지, 어느 딜러에 맡길지를 전화와 감으로 정한다**

| 리드 유입 | → | 일일이 유효성 확인 | → | 경험으로 딜러 선택 |
|---|---|---|---|---|
| • **소음이 신호를 묻는다**<br>• **유효 리드는 100건 중 약 20건(가정)** |  | • **늦으면 기회가 사라진다**<br>• **유효 고객 여부를 세일즈에서 개별연락** |  | • **판단이 사람에게 묶여 있다**<br>• **사람이 바뀌면 경험이 사라진다** |

- **누가:** 딜러 판매가 주력인 제조사의 본사 세일즈 담당자
- **문제:** 문의를 하나하나 전화로 확인하고 딜러도 경험으로 골라, 진짜 고객에게 쓸 시간을 놓침
- **얼마나:** 리드 100건 중 약 20건만 유효(실무 경험 기반 가정)
  - 업계도 영업 단계까지 가는 리드를 10~40%로 봄(Salesforce)
  - 1시간 안에 연락하면 의사결정자와 대화 가능성 약 7배(HBR, 2011)

### 2. 해결 방식

**원칙:** AI가 준비하고 근거를 붙이고, 사람은 승인만 하고, 결과가 다음 판단의 재료가 된다.

**서비스 URL:** https://onemorestep-wheat.vercel.app/

**활용법:** "선별 시작" → **선별 → 넘길 곳·딜러 추천 → 결정 카드** 준비, 담당자는 승인만 처리.

| 리드 유입 | → | 선별 | → | 넘길 곳 | → | 딜러 추천 | → | 담당자 승인 | → | 결과 기록 |
|---|---|---|---|---|---|---|---|---|---|---|
| • **선별 시작 클릭**<br>&nbsp;&nbsp;◦ 홈페이지 문의 |  | • **5갈래로 분류**<br>&nbsp;&nbsp;◦ 기관 실재 확인<br>&nbsp;&nbsp;◦ 소재지 확인<br>&nbsp;&nbsp;◦ 도메인 대조<br>&nbsp;&nbsp;◦ 메모 의도 판단<br>• **근거를 붙임**<br>&nbsp;&nbsp;◦ 링크·검색 시각 |  | • **유효 → 국가 딜러**<br>• **확인 → 권역팀**<br>&nbsp;&nbsp;◦ 애매<br>&nbsp;&nbsp;◦ 국가 확인<br>&nbsp;&nbsp;◦ 제휴 확인<br>• **기타 처리**<br>&nbsp;&nbsp;◦ 채용: 인사팀<br>&nbsp;&nbsp;◦ 무효: 일괄 정리 |  | • **90일 실적 순위**<br>&nbsp;&nbsp;◦ deal / no deal<br>&nbsp;&nbsp;◦ 미응답 반영<br>&nbsp;&nbsp;◦ 이유 표시<br>• **신규면 지역 확인** |  | • **승인은 한 번**<br>&nbsp;&nbsp;◦ 질문 카드<br>&nbsp;&nbsp;◦ 근거 3개 제시<br>&nbsp;&nbsp;◦ 테스트 메일만<br>• **대안도 선택**<br>&nbsp;&nbsp;◦ 딜러 변경<br>&nbsp;&nbsp;◦ 전화·무효 |  | • **다음 순위 반영 ↻**<br>&nbsp;&nbsp;◦ 전달 결과 기록<br>&nbsp;&nbsp;◦ 미응답 시 재배정 |

- **유효한 대상에만 집중하도록 자동으로 필터링**
  - 기관 조사·사칭·문의 의도·도메인·질문 내용 검증으로 **유효 / 확인 / 기타 분류**
  - 최근 90일 딜러 실적을 순위에 자동 반영, 리드 정보는 마케팅 요청까지 넘김
- **테스트 데이터 1,000건 검증 결과**

| 항목 | 기존 (가정) | One More Step 적용 결과 |
|---|---|---|
| 전체 리드 | 1,000 | 1,000 |
| 고객 컨택 대상 | 1,000 (전부 확인) | **410 (−59%)** |
| 딜러 전달 리드 | 289 (오류 포함) | 109 (확실한 리드만 전달) |
| (자동) 내용 보완 요청 메일 | 0 | 203 |
| 무효 처리 (스팸, 홍보) | 0 | 278 |
| 소요 시간 | 7-14일 (누락될 수 있음) | **약 10분 내 처리 완료 & 1시간 이내 컨택 가능** |

### 3. Liner API 활용

| 목적 | Liner API | 역할 |
|---|---|---|
| 소속 기관 조사 | Liner Search | "기관명 + 국가/업종" 검색으로 실재·소재지·공식 도메인 확인 |
| 사칭 걸러내기 | Liner Search 결과 | 공식 도메인과 메일 도메인을 대조해 닮은꼴을 사칭 의심으로 표시 |
| 문의 의도 판단 | Liner Router(모델) | 메모 의도(구매·제휴·채용·과제·영업·스팸) 판단, 근거 문장 인용 |
| 도메인 소유 판단 | Liner Router(모델) | 규칙이 못 본 도메인만 검색 결과로 소유 판단, 원문·URL 인용 |
| 담당자 질문 | Liner Router(모델) | 애매 리드의 질문 작성. 근거는 선별 기록에서, 실패 시 기본 문구 |
| 마케팅 채널 초안 | Liner Router + Search | 채널별 초안과 근거 링크. 근거 없는 문장은 "확인 필요" 표시 |

- **AI가 판단하고 규칙이 지킨다**
  - 인용이 실제 메모·검색 결과에 있을 때만 모델 답을 씀 & 모델이 실패하면 규칙으로 선별
- **공개 정보로 확인하지 못하면 "유효"를 주지 않는다**
  - Liner 검색으로 소속을 확인하지 못하면 유효 불가 & 검색 실패는 "외부 확인 실패"로 무효 처리.
