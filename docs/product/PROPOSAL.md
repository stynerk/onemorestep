## 미리내: 쏟아지는 리드 속에서 진짜 고객을 먼저 찾아, 믿을 만한 딜러에게 바로 넘기는 세일즈 에이전트

### 1. 누가, 어떤 문제로, 얼마나 불편한가

**누가:** 딜러망으로 제품을 파는 제조사(예: 가상의 의료기기 제조사 Medicom)의 본사 세일즈 담당자.

**지금 일하는 방식:** 홈페이지 문의(리드)가 들어오면 담당자가 거의 모든 리드에 전화를 걸어 진짜 고객인지 확인하고, 그 지역 딜러 중 한 곳을 골라 넘긴다. 팀 대표(HJ)가 제조사 세일즈 조직에서 직접 겪은 업무 흐름을 회사명과 내부 수치 없이 일반화했다.

**문제 세 가지:**
1. **소음이 신호를 묻는다.** 문의의 상당수는 스팸, 영업 제안, 학생 과제, 구직, 허위 정보다. B2B 폼 제출 100만 건 이상을 분석한 자료에서 영업 전에 걸러진 비율은 18.7~37.7%, 대기업 대상은 71.2%였다(RevenueHero, 2025). 미리내의 시나리오는 월 약 200건 중 약 80%가 비적격이라고 **가정**한다.
2. **늦으면 기회가 사라진다.** 미국 기업 2,241곳에 웹 문의를 보낸 조사에서 1시간 안에 답한 곳은 37%였고, 1시간 안에 연락한 기업은 1시간 늦은 기업보다 의사결정자와 대화할 가능성이 약 7배 높았다(Harvard Business Review, 2011). 비적격 리드에 전화를 거는 동안 진짜 고객은 기다린다.
3. **판단이 사람에게 묶여 있다.** "진짜 고객인가"와 "어느 딜러가 믿을 만한가"는 담당자 개인의 경험으로 정한다. 사람마다 판단이 다르고, 담당자가 바뀌면 경험이 사라진다. 예전에 거래한 딜러에게 넘겼는데 대응이 느려 기회를 놓치기도 한다.

### 2. 해결 방식

담당자가 문의함에서 "판정 시작"(또는 리드별 판정)을 누르면, 미리내가 **판정 → 넘길 곳·딜러 추천 → 결정 카드**를 준비하고 담당자에게는 추천 승인만 요청한다.

| 단계 | 미리내가 하는 일 |
|---|---|
| 판정 | 소속 기관이 실재하는지, 소재지가 리드 국가와 맞는지, 이메일 도메인이 기관 공식 도메인과 맞는지를 공개 정보로 확인하고, 메모의 의도(구매·제휴·영업·과제)를 읽어 **유효 / 애매 / 국가 확인 / 제휴 확인 / 무효**로 나눈다. 확인된 근거에는 링크와 검색 시각을 붙인다. 넘길 곳을 함께 표시한다: 유효는 국가 딜러, 애매·국가 확인·제휴 확인(사칭 의심 포함)은 권역 세일즈팀, 채용 문의는 인사팀, 그 밖의 무효는 넘기지 않음 |
| 딜러 추천 | 리드 국가 딜러의 **최근 90일 전달 결과(deal / no deal / 미응답)**로 순위를 매기고 이유를 보인다. 이력이 적은 신규 딜러만 있으면 지역 담당자에게 먼저 확인한다 |
| 결정 카드 | "이 리드를 ○○ 딜러에게 넘길까요?" + 근거 3개. 추천이 맞으면 **승인** 한 번이고, 아니면 **딜러 변경**(후보 선택과 사유 입력) / **전화 필요** / **무효 처리**를 고른다. 승인하면 딜러용 요약 메일 이벤트가 생긴다(시연·테스트 환경에서는 테스트 수신함으로만 가고, 공개 시연 주소는 메일을 보내지 않는다) |

- 무효는 이유와 함께 묶어 한 번에 확인하고, 전화는 근거가 부족한 "애매" 건에만 건다. 모든 전화를 없앤다고 주장하지 않는다.
- 국가가 어긋난 리드에는 국가 확인 메일을, 제휴 제안에는 세부 사항 요청 메일을 만든다(테스트 수신함으로만 발송).
- 딜러가 응답 기한을 넘기면 미리내가 다음 딜러로 재배정을 제안하고, 미응답 기록이 쌓이면 다음 리드의 딜러 순위가 바로 바뀐다. **제조사만 가진 기록이 판단의 재료가 되는 반복 루프**다.

**시연 결과 (확정 엔진, 2026-11-20 측정):** 가상 리드 30건(13개 나라)을 실무자가 먼저 매긴 정답과 비교했다. 저장된 검색 근거로 판정 30/30, 넘길 곳 30/30, 실제 Liner 검색으로 판정 27/30이고, 두 방식 모두 유효 리드를 무효로 버린 건은 0건이다. 무효 물량 맨 뒤에 묻혀 있던 리드가 판정 직후 맨 위로 올라온다.

**미리 보지 않은 평가 70건:** 실무자가 엔진을 보지 않고 매긴 정답과 비교하면 판정 33/70(47%), 넘길 곳 38/67이다(원본 정답 기준 23/70, 가상 기관 11건을 라벨링 때 실재 여부를 볼 수 없어 무효로 정정). 한계도 그대로 밝힌다: 실제 기관의 유효 리드 15건 중 12건은 공식 페이지를 확인하지 못해 "애매"로 권역 세일즈팀에 넘겼고, 3건은 검색에서 기관 근거를 찾지 못해 무효로 갔다. 딜러로 바로 넘긴 건은 없다. 미리내는 확신이 없으면 사람에게 넘기도록 만들었지만, 근거 없음을 무효로 보내는 3건은 다음 개선 대상이다(공식 페이지 확인 범위 넓히기, 근거 없음은 애매로 보내는 조건).

### 3. Liner API 활용

| 쓰는 곳 | API | 역할 |
|---|---|---|
| 소속 기관 조사 | Liner Search | 리드마다 "기관명 + 국가", "기관명 + 업종"을 검색해 기관 실재, 소재지, 공식 도메인을 확인한다. 유효 판정의 외부 근거다 |
| 사칭 걸러내기 | Liner Search 결과 | 검색으로 확인한 공식 도메인과 리드 이메일 도메인을 대조해 닮은꼴 도메인을 사칭 의심으로 표시해 권역 세일즈팀이 결정하게 넘긴다 |

- **Liner가 빠지면 판정이 성립하지 않는다.** 소속을 공개 정보로 확인하지 못하면 미리내는 "유효"를 주지 않는다. 그래서 외부 근거가 없으면 판단이 다시 담당자의 경험으로 돌아간다.
- 실제 키로 공개 기관 5곳 × 2질의를 검색해 10회 모두 정상 응답을 받았다. 실재·업종·소재지·공식 도메인 네 항목을 모두 확인한 곳은 3곳이었다(2026-11-18).
- 검색 실패나 시간 초과는 "외부 확인 실패"로 표시하고 애매로 둔다. 화면은 멈추지 않는다.

### 4. 확장 가능성

- **딜러·대리점망을 가진 B2B 판매 전반 (구현된 구조 그대로):** 리드가 기관·기업 소속이고 딜러·대리점·리셀러가 있는 업이면 같은 엔진이 그대로 돈다(산업재 총판, 분석 장비, B2B SaaS 리셀러). 바꿀 것은 딜러 표, 판정 기준값(집계 기간 90일, 이력 기준 3건, 가중치), 나라→권역 매핑뿐이고 모두 코드가 아니라 정책 파일에서 바꾼다.
- **조직의 기억:** 신입 담당자도 같은 근거로 판단하고, 결정과 딜러 결과가 기록으로 남아 다음 추천을 바꾼다. 개인 경험이 조직의 자산이 된다.
- **같은 원칙의 다른 업무 (다음 버전, 미구현):** 팀 대표가 겪은 마케팅 협조 요청 처리에도 "AI가 준비하고 사람은 승인한다"는 원칙을 적용할 수 있다.

**공통 원칙: AI가 준비하고 근거를 붙이고, 사람은 승인만 하고, 결과가 다음 판단의 재료가 된다.**

미리내는 대회 개발 기간(2026-11-12~)에 새로 작성했다. 시연 데이터의 회사·인물·리드는 모두 가상이고, 소속 기관 이름만 공개 정보다.
