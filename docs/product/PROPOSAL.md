## 미리내: 쏟아지는 리드 속에서 진짜 고객을 먼저 찾아, 믿을 만한 딜러에게 바로 넘기는 세일즈 에이전트

### 1. 누가, 어떤 문제로, 얼마나 불편한가

**누가:** 딜러망으로 제품을 파는 제조사(예: 가상의 의료기기 제조사 Medicom)의 본사 세일즈 담당자.

**지금 일하는 방식:** 홈페이지 문의(리드)가 들어오면 담당자가 거의 모든 리드에 전화를 걸어 진짜 고객인지 확인하고, 그 지역 딜러 중 한 곳을 골라 넘긴다. 팀원이 실제로 겪은 업무 흐름이다.

**문제 세 가지:**
1. **소음이 신호를 묻는다.** 문의의 상당수는 스팸, 영업 제안, 학생 과제, 구직, 허위 정보다. B2B 폼 제출 100만 건 이상을 분석한 자료에서 영업 전에 걸러진 비율은 18.7~37.7%, 대기업 대상은 71.2%였다(RevenueHero, 2025). 미리내의 시나리오는 월 약 200건 중 약 80%가 비적격이라고 **가정**한다.
2. **늦으면 기회가 사라진다.** 미국 기업 2,241곳에 웹 문의를 보낸 조사에서 1시간 안에 답한 곳은 37%였고, 1시간 안에 연락한 기업은 1시간 늦은 기업보다 의사결정자와 대화할 가능성이 약 7배 높았다(Harvard Business Review, 2011). 비적격 리드에 전화를 거는 동안 진짜 고객은 기다린다.
3. **판단이 사람에게 묶여 있다.** "진짜 고객인가"와 "어느 딜러가 믿을 만한가"는 담당자 개인의 경험으로 정한다. 사람마다 판단이 다르고, 담당자가 바뀌면 경험이 사라진다. 예전에 거래한 딜러에게 넘겼는데 대응이 느려 기회를 놓치기도 한다.

### 2. 해결 방식

미리내는 리드가 들어오면 **판정 → 딜러 추천 → 결정 카드** 세 단계를 먼저 끝내 두고, 담당자에게는 승인만 요청한다.

| 단계 | 미리내가 하는 일 |
|---|---|
| 판정 | 소속 기관이 실재하는지, 소재지가 리드 국가와 맞는지, 이메일 도메인이 기관 공식 도메인과 맞는지를 공개 정보로 확인하고, 메모의 의도(구매·제휴·영업·과제)를 읽어 **유효 / 애매 / 국가 확인 / 제휴 확인 / 무효**로 나눈다. 판정마다 근거 링크와 검색 시각을 남긴다 |
| 딜러 추천 | 리드 국가 딜러의 **최근 90일 전달 결과(deal / no deal / 미응답)**로 순위를 매기고 이유를 보인다. 이력이 적은 신규 딜러만 있으면 지역 담당자에게 먼저 확인한다 |
| 결정 카드 | "이 리드를 ○○ 딜러에게 넘길까요?" + 근거 3개. 담당자는 **승인 / 딜러 변경 / 전화 필요 / 무효 처리** 중 하나만 누른다. 승인하면 딜러용 요약 메일이 나간다 |

- 무효는 이유와 함께 묶어 한 번에 확인하고, 전화는 근거가 부족한 "애매" 건에만 건다. 모든 전화를 없앤다고 주장하지 않는다.
- 국가가 어긋난 리드에는 국가 확인 메일을, 제휴 제안에는 세부 사항 요청 메일을 자동으로 보낸다.
- 담당자가 입력한 딜러 결과가 쌓이면 다음 리드의 딜러 순위가 바로 바뀐다. **제조사만 가진 기록이 판단의 재료가 되는 반복 루프**다.

**시연 결과 [Cap #32 결과로 채움]:** 가상 리드 30건(13개 나라)을 실무자가 먼저 매긴 정답과 비교한 판정 일치율 ○/30, 유효 리드 놓침 ○건, 딜러 추천 일치율 ○/8. 무효 물량 맨 뒤에 묻혀 있던 리드가 판정 직후 맨 위로 올라온다.

### 3. Liner API 활용

| 쓰는 곳 | API | 역할 |
|---|---|---|
| 소속 기관 조사 | Liner Search | 리드마다 "기관명 + 국가", "기관명 + 업종"을 검색해 기관 실재, 소재지, 공식 도메인을 확인한다. 유효 판정의 외부 근거다 |
| 사칭 걸러내기 | Liner Search 결과 | 검색으로 확인한 공식 도메인과 리드 이메일 도메인을 대조해 닮은꼴 도메인을 사칭 의심으로 거른다 |
| [선택] 판정 이유·딜러 요약 문장 | Liner Model API | [11-22 구현 여부에 따라 넣거나 뺀다] |

- **Liner가 빠지면 판정이 성립하지 않는다.** 소속을 공개 정보로 확인하지 못하면 미리내는 "유효"를 주지 않는다. 그래서 외부 근거가 없으면 판단이 다시 담당자의 경험으로 돌아간다.
- 실제 키로 공개 기관 5곳 × 2질의를 검색해 10회 모두 정상 응답을 받았다. 실재·업종·소재지·공식 도메인 네 항목을 모두 확인한 곳은 3곳이었다(2026-11-18).
- 검색 실패나 시간 초과는 "외부 확인 실패"로 표시하고 애매로 둔다. 화면은 멈추지 않는다.

### 4. 확장 가능성

- **같은 업종의 다른 판매망:** 리드가 기관·기업 소속이고 딜러·대리점·리셀러가 있는 업이면 같은 틀이 그대로 돈다(산업재 총판, 분석 장비, B2B SaaS 리셀러). 바꿀 것은 딜러 표, 판정 기준값(집계 기간, 가중치), 지역 매핑뿐이고 모두 정책 파일로 바꾼다.
- **다른 직무:** 팀원이 겪은 또 하나의 업무인 **마케팅 협조 요청**도 같은 원칙으로 풀린다. 요청이 오면 AI가 빠진 정보를 대화로 받고, 반복 유형을 템플릿으로 콘텐츠를 구성하고, 담당자는 승인만 한다. 미승인 사유는 다음 구성의 재료가 된다(다음 버전).
- **조직의 기억:** 신입 담당자도 같은 근거로 판단하고, 판단과 결과가 기록으로 남는다. 개인 경험이 조직의 자산이 된다.

**공통 원칙: AI가 준비하고 근거를 붙이고, 사람은 승인만 하고, 결과가 다음 판단의 재료가 된다.**
