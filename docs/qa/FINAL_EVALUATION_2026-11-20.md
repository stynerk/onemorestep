# #32 확정 엔진 평가와 공개 QA

2026-11-20 KST. 판정 기준 커밋은 [8d4f0ac](https://github.com/stynerk/onemorestep/commit/8d4f0ac64e38f36bd6ed3cea55e67eb962793d4b)이다. 입력은 이 커밋의 `docs/product/EVAL_DATA.md`, 블라인드 정답은 PR #53 `f120da7`의 `docs/qa/EVAL_ANSWERS_HJ.csv`를 사용했다. 시연 30건은 시연용 저장 근거와 함께 구성한 세트다. 평가 70건은 별도 입력과 HJ 정답으로 측정했다. 정답은 평가 스크립트에서만 대조했고, 평가 전후 판정 엔진과 정책 파일은 동일하다.

주 지표는 5개 판정의 정확 일치율이다. 경로는 HJ 정답이 유효인 건에 대해 딜러로 갔는지만 비교한다. 나머지는 권역 세일즈팀, 인사팀, 넘기지 않음의 범주를 비교한다. 세부 딜러 및 권역 이름은 채점 대상에서 제외한다. HJ가 무효·권역팀으로 적은 E09·E59·E67은 판정에 포함하고 경로에서 제외했다. 경로 일치율은 판정 일치 여부와 독립적으로 계산했다. 애매 이관은 실제로 애매에 분류되어 권역팀으로 간 건수다.

엔진이 반환한 `regional-sales`는 권역 미지정이어도 경로 범주에 포함했다. 이 지표는 실제 메일 발송이나 배정을 뜻하지 않는다.

### 측정 재현

Liner Web Search API v1을 2026-11-20 23:43:06~23:47:32 KST에 시연 56회, 평가 114회 호출했다. 170회 모두 HTTP 200이었다. 기록 170개를 외부 호출 없이 재생해 두 세트의 혼동행렬, 경로 집계, 불일치 사유가 같은 것을 확인했다. 기록 키는 세트 입력·정답과 요청 본문의 SHA-256을 포함한다. 검색 응답은 Git에서 제외된 로컬 `.cache/final-forwarding-recordings/`에 보관한다.

`npm ci` 이후 PR #53 `f120da7`의 CSV를 `.cache/EVAL_ANSWERS_HJ.csv`에 둔다. CSV를 평가 전용 JSON으로 변환할 수 있다. 변환된 JSON과 CSV의 저장 모드 집계가 일치함을 확인했다.

```powershell
npx tsx scripts/evaluate-final-forwarding.ts labels .cache/EVAL_ANSWERS_HJ.csv | Set-Content -Encoding ascii .cache/EVAL_ANSWERS_HJ.json
npx tsx scripts/evaluate-final-forwarding.ts sample .cache/EVAL_ANSWERS_HJ.csv
npx tsx scripts/evaluate-final-forwarding.ts replay .cache/EVAL_ANSWERS_HJ.csv
```

기록이 없는 경우 `capture` 모드는 Liner 키가 있는 로컬 환경에서 검색을 실행하고 응답을 기록한다. `replay` 모드는 같은 지문의 기록이 있을 때만 집계한다.
