# 대규모 보조 평가 1,000건 — 2026-11-25

Gemini 라벨·HJ 확인 기준으로 선별 **579/1,000 (57.9%)**, 넘길 곳 **528/1,000 (52.8%)**가 일치했다. 유효→무효는 **104건**, 거짓 유효는 **8건**이다. 대표 수치는 사람 정답 블라인드 평가의 선별 **17/30 (56.7%)**이다. [블라인드 평가 보고서](BLIND_EVALUATION_2026-11-23.md)

## 측정 기준

- 시드 20261125로 만든 가상 문의 1,000건(X0001~X1000)이다. 실제 기관 78곳, 유형 12개, 언어 6개가 포함됐다. [생성 명세](LARGE_EVAL_SPEC.md) · [입력 평가표](LARGE_EVAL_1000.csv)
- HJ가 전달한 Gemini 라벨 1,000행의 입력 6열이 평가표와 일치했다. 정답 CSV를 바이트 그대로 보존하고 라벨과 이유를 수정하지 않았다. 라벨 분포는 유효 389, 애매 311, 국가 확인 100, 제휴 확인 57, 무효 143이다. [답안 원본](LARGE_EVAL_1000_ANSWERS_GEMINI.csv)
- 사람 정답 100건과 Gemini 라벨의 일치율 검증은 HJ가 정한 이번 범위에서 제외됐다. 이 보고서의 일치율은 수신 답안과 엔진 결과를 대조한 값이다.
- 빈 평가표의 운영 입력만 당시 main `ca0cf6e299772744aa5e734fab99dbe96cbed7be`의 의료기기 실시간 선별 서비스에 전달했다. 채점은 새 실측의 예측이 저장된 뒤 수행했다. 후속 질문 문구 생성과 사용자 답변은 평가 경로에서 제외했다.
- 넘길 곳은 국가별 딜러, 권역별 세일즈팀, 인사팀과 없음으로 정확히 대조했다. 무효 라벨의 빈 넘길 곳 113건은 채점에서 ‘없음’으로 읽었다. 엔진의 미지정 권역 161건은 명시된 권역과 일치로 세지 않았다. 모든 지표는 해당 묶음 전체를 분모로 사용한다.
