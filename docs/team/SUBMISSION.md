## 꼭 지킬 것

- 회사 내부 문서, 영업비밀, 고객 정보, 개인정보를 쓰지 않는다. 시연 데이터는 가상 데이터나 공개 데이터만 쓴다.
- 아이디어 제공자의 실명과 카톡 원본은 영상, 기획서, 저장소에 넣지 않는다.
- 기존 결과물을 발전시킨 부분이 있으면 README와 기획서에 기존 부분과 새로 만든 부분을 나눠 적는다. 미리내는 11-12부터 새로 작성한다.
- 개발에는 신청서에 등록한 팀원만 참여한다.

## 우리 쪽에 주는 영향

- 심사위원은 운영팀 키만 넣고 실행한다. 키를 넣으면 실제 Liner 호출로 동작해야 하고, README만 보고 바로 실행돼야 한다. 지금 기본값은 `LINER_MODE=sample`이라 키만 넣어서는 실제 호출이 되지 않는다(Cap 확인 필요).
- 저장소 공개 전환 전에 git 이력 전체에서 키와 개인정보를 검사한다.
- 기획서는 1~2페이지 PDF다. `docs/product/PLAN.md`에서 요약해 만든다.
