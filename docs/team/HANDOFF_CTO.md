# CTO 인수인계

마지막 갱신: 2026-11-13, PC·모바일 메인 홈 와이어프레임 작성

## 지금 상태

- HJ가 세 가설 페르소나 기반 와이어프레임의 PC 웹/모바일 버전과 상세 패널 뒤의 메인 홈을 요청했다. 앞선 생성 이미지가 채널에서 보이지 않았다고 알렸다.
- design-main-home-wireframes 브랜치를 최신 origin/main에서 만들고 docs/design/main-home-v1에 desktop.png, mobile.png와 설명·생성 프롬프트를 저장했다.
- 기본 제공 image_gen으로 두 이미지를 생성했다. PC는 왼쪽 탐색과 기회 3열, 모바일은 단일 열과 하단 탐색이다. 상세 패널과 팝업이 없는 홈이다.
- 모든 프로필·기회·건수·상태는 가상 예시다. 인터뷰 대상의 자율주행 사업 정보는 사용하지 않았다.
- 확정 기획이나 제품 구현으로 취급하지 않는다. PLAN.md와 제품 코드는 변경하지 않았다. 기존 Issue #2 재점검 PR #6과 별도 브랜치로 분리했다.
- Discord 이미지 도구의 인라인 전달은 확인하지 못해 공개 저장소 브랜치의 PNG 링크로 공유한다.

## 보존할 제품·운영 상태

- 개발 세팅 PR #3·#5는 병합됐다. 기획은 사업 맥락에 맞는 기회 발견에서 다음 행동 준비까지 지원하는 v0.2 초안이다.
- 페르소나와 놓친 기회 이야기는 검증용 가설이다. 실제 인터뷰나 수요 검증 결과로 단정하지 않는다.
- Liner 팀별 USD 200 지급 예정 안내는 받았으나 실제 잔액·키·인증 호출은 별도 확인이 필요하다. 승인 전 유료 호출을 보류하고 예시 모드를 유지한다.
- 저장소 공개 전환은 HJ 요청에 따라 완료했으며 GitHub API의 PUBLIC 상태를 확인했다.
- Issue #2 재호출에는 Codex 환경 생성 안내가 반환됐다. 수동 기록 PR #6은 자동 연결 성공을 뜻하지 않는다.
- 제출 마감은 11-25 23:59 KST, 소스/5분 이내 영상/1~2페이지 정도 PDF를 준비한다. 일반 병합은 PM·CTO가 결정하고 배포·결제·최종 제출은 HJ 권한이다.

## 검증과 제한

- 두 생성 이미지를 시각적으로 확인했다. 한글, 카드 3종, PC/모바일 배치와 상세 패널 부재를 확인했다.
- 모바일은 전체 스크롤 영역 이미지다. 실제 기기 한 화면에 전부 보이는 레이아웃이 아니다.
- 이미지와 문서만 변경했다. 코드·패키지·실제 API를 실행하지 않았고 제품 테스트는 재실행하지 않았다.
- 클릭 가능한 프로토타입, 목표 선택 동작, 사용자 테스트는 아직 없다.

## 다음 작업

1. HJ와 PM이 PC/모바일 메인 홈 초안을 검토한다. 목표 선택이 정렬인지 필터인지와 상세 화면 진입 흐름은 미확정이다.
2. 인터뷰와 페르소나 검증을 바탕으로 주 대상과 MVP 범위를 정한다.
3. 확정된 기능 Issue에 따라 제품을 구현한다. 이 디자인 초안 브랜치는 검토 전 main에 병합하지 않는다.

- 다음 작업: 이미지 링크로 검토받고 승인된 범위만 구현 Issue로 넘긴다.
