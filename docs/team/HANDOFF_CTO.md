## 데이터 구성

- scenarios.js에 회사 소개·단계·목표·고민·자원·경쟁사, 사실/가설 표시, 테마 카드 3개, 참고 문서 3개, 가상 일정 2개, 반복 업무·관심 주제, 준비 중 1건/체크 1개를 구성했다.
- 루프오토는 관제 시제품이 있고 상용 운영 전인 B2B 스타트업이다. 첫 파일럿 파트너·역할·검증 범위를 준비한다. 주행 판단/차량 제어는 협력사 영역으로 가정했다.
- 지원 카드는 가상 서울 모빌리티 실증 협력, 시장 카드는 가상 경쟁사의 정비 이력 통합, 회사 과제는 파일럿 전 책임·승인 질문이다.
- 전용 초안 3종과 해당 테마 문서 발췌가 이어진다. 초기화 시 선택 회사의 참고 문서·지도·준비 과제도 복원한다. 다른 회사 데이터는 건드리지 않는다.
- 실제 기업·공고·발표·일정·법적 요건·차량 운영 절차가 아니다. 가상 문서의 사실 표시는 시나리오 안에서의 구분이다.
- 자세한 픽스처·사용법·제한은 docs/product/mockup/SCENARIOS.md에 기록했다.

## 확인한 것과 남은 제한

- Chrome 실제 클릭: 자율주행 프로필·카드·지원 초안·제품 참고자료 연결, 지도 일정/주제/준비 항목, 기존 회사로 전환 확인.
- 이후 긴 브라우저 검증이 시간 초과로 중단됐고 재연결도 프로세스 종료 오류였다. 왕복 전환 전체 UI 검사·새 선택 메뉴의 모바일 시각 확인은 미완료다. 승인 거절이 아니며 다른 도구로 우회하지 않았다.
- 실제 loadState를 격리 실행해 두 회사의 저장 키 분리·각각의 수정값 보존·카드 분리·잘못된 시나리오 기본값 복귀를 확인했다. 가상 데이터 필수 필드/테마/체크 수 정합성, JS 구문·diff 검사 통과.
- 이번은 시나리오 데이터 묶음의 전환이다. FLOW_AUDIT.md에 기록한 목표 변경→카드 재판단, 초안 재검토, 일정/작업 통합, 실행 결과 피드백 미구현은 해결하지 않았다. 화면에도 이 제한을 표시했다.
- 기존 파일 가져오기 전체 브라우저 검증은 이전 자동 승인 거절로 미완료이며 이번에 재시도하지 않았다. 실제 Liner 호출·OAuth·자동 실행은 없다.
