## 구현과 검증

- 기존 설정 6개·사실/가설, 가상 브리핑·테마, 상세·지역 되묻기, 체크·초안, 준비/완료/보류를 유지했다.
- 회사 자료실에 프로필과 사업·제품 자료, 조사, 업무 이력을 모았다. 메모와 TXT/MD 파일·폴더를 한 번 읽어 미리보는 기능, 링크+복사 본문 등록을 구현했다. 파일당 32KB/본문 8,000자, 전체 30개 제한이다.
- 노션·드라이브·웹 링크는 수동 본문 입력 경로다. OAuth·URL 자동 수집·지속 동기화는 없다.
- 자료별 사실/가설·출처·테마를 지정하고 상세에서 원문을 확인한다. 새 초안에 최대 3개 자료의 앞 500자를 덧붙인다. 자동 분석·추론이 아니다.
- localStorage로 이 브라우저에만 저장한다. 수정·삭제·초기화 가능하다. 기존 저장 초안은 보존하므로 자료 변경·삭제 후 기존 발췌는 직접 수정한다.
- 소라 원본 index.html은 보존했다. 배포 첫 화면은 interactive.html을 복사했다. 기존 Next.js·MVP/PLAN 정본은 변경하지 않았다.
- 로컬/공개 Chrome에서 자료 등록·수정·삭제, 새로고침 후 유지, 테마 상세·새 초안 발췌, 초기화를 확인했다. 테스트 자료는 초기화했다.
- HTML 입력 문자열 출력과 javascript: URL 차단을 확인했다. PC 1440px/모바일 390px 자료실·미리보기 가로 넘침 없음. 캡처 knowledge-desktop.jpg, knowledge-mobile.jpg. 임시 뷰포트 해제.
- 파일 선택창은 열었으나 파일 전달은 브라우저 자동 승인 검토에서 거절됐다. 로컬 페이지의 파일 전달 권한 미승인 사유였다. 우회하지 않았고 실제 파일 선택부터 저장까지 검증은 미완료다.
