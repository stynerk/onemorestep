## 구현

- 목표·현재 단계, 주요 일정과 마감, 반복 업무, 관심 주제, 준비 중인 일을 지도에서 확인한다. PC는 지도+편집창, 모바일은 한 열이다.
- 목표·단계·고민·자원을 회사 프로필과 공유하며 직접 편집할 수 있다. 바꾼 목표는 브리핑 연결 정보와 새 템플릿에 반영된다. 이미 저장한 초안은 덮어쓰지 않는다.
- 일정 이름·날짜 추가/삭제와 날짜순·D-day 표시(최대 20개), 반복 업무·주제 목록 편집(최대 12개/항목당 180자), 준비 상세·회사 자료 화면 연결을 구현했다.
- 상태는 기존 localStorage 키 안에 workMap 필드로 추가해 기존 회사 자료·체크·초안을 보존한다. 새로고침 후 유지, 전체 목업 초기화 시 지도도 초기화한다.
- 업무 지도는 work-map.js. 별도 패키지·API 없이 정적 모듈로 만들었다. build-pages.cjs 산출물은 index.html, knowledge.js, work-map.js, .nojekyll 네 개다. 사용자 입력값은 배포 파일에 없다.
- 회사 자료실은 메모/TXT·MD 일회성 가져오기와 미리보기, 출처+복사 본문 등록, 사실/가설·테마, 상세·새 초안 원문 발췌를 유지한다. 노션·드라이브는 수동 입력 경로다.
- 소라 원본 index.html과 기존 Next.js·기획 정본은 보존했다. 배포 첫 화면은 interactive.html을 복사한 것이다.

## 검증과 제한

- Chrome 실제 클릭: 목표·단계 편집→회사 설정/브리핑/새 초안 반영, 일정 추가·삭제/D-day, 반복 업무·주제 편집/빈 목록, 새로고침 유지, 준비 항목 연결, 초기화.
- HTML 문자열 출력, 1440px PC/390px 모바일 업무 지도·회사 설정 모달 가로 넘침 없음, 모바일 다섯 메뉴 버튼을 확인했다. 임시 뷰포트 해제. 테스트 데이터 초기화.
- JS·서버·빌드 파일 구문 검사와 diff 검사 통과. 독립 정적 목업이라 기존 Next 빌드는 재실행하지 않았다. 화면 기록 work-map-desktop.jpg, work-map-mobile.jpg.
