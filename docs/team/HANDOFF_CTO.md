## 검증

- npm ci 재설치, npm test 7건, npm run lint, npm run typecheck 및 최종 npm run build 통과.
- 실제 개발 서버에서 GET / 200, POST /api/research 200과 예시 출처 2건/안내, 잘못된 입력 400을 확인했다.
- 브라우저 연결 도구가 시간 초과해 클릭 동작과 시각 검증은 확인하지 못했다.
- npm audit --omit=dev는 취약점 0건. 전체 audit의 개발용 린터 하위 의존성 중간 등급 7건은 호환 범위 수정으로 해소되지 않아 기술 문서와 PR에 남긴다.
- .env와 .env.local은 gitignore 대상이다. 실제 키를 읽거나 커밋하지 않았다. 배포, 가입, 결제는 수행하지 않았다.
- Next.js의 AGENTS.md 자동 변경은 agentRules=false로 비활성화하고 생성 부분을 제거했다. 시행착오에 원인과 대응을 기록했다.
