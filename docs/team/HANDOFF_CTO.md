- 작업 브랜치는 issue-7-web-mockup, 추적 Issue는 #7이다. 최종 기획 정리와 공유는 소라가 맡는다.
- docs/product/mockup/interactive.html은 설치 없이 열 수 있는 정적 HTML/CSS/JS 목업이다. 서버가 필요하면 node docs/product/mockup/serve.cjs로 실행한다.
- 사용자 검토용 로컬 서버를 http://127.0.0.1:3107 에 유지했다. 외부 공유용 배포는 하지 않았다.
- 회사 설정 6개와 사실/가설 구분, 예시 브리핑, 테마 필터, 상세, 지역 되묻기, 체크리스트와 초안, 준비/완료/보류, 초기화가 동작한다.
- localStorage로 같은 브라우저에서 상태가 유지된다. 모든 정보와 출처는 가상 예시다. 실제 Liner/LLM 호출, 추천 엔진, 외부 신청·전송은 구현하지 않았다.
- 회사 입력을 바꾸면 화면의 연결 정보와 템플릿 내용이 바뀌지만 실제 재검색·추론은 하지 않는다. 목업을 에이전트 완성이나 사용자 가치 검증 결과로 취급하지 않는다.
- README와 PC/모바일 검토 화면 PNG를 같은 경로에 저장했다. 소라가 같은 브랜치에 남긴 참고용 초안 index.html(daa37ab)은 원문 그대로 보존했다. 검증 버전은 interactive.html이다. 기존 Next.js 검색 뼈대, PLAN.md와 MVP.md는 변경하지 않았다.

## 검증

- Chrome에서 회사 목표 수정, 테마별 필터·빈 상태, 상세 열기, 지역 답변과 조건 대조 변화, 초안·체크 상태 저장을 실제 클릭으로 확인했다.
- 새로고침 후 목표·지역·체크·초안 유지, 준비 목록 이동, 완료·보류 처리와 초기화를 확인했다.
- 지역이 다르면 불일치로 표시된다. 지역을 답하기 전 편집 중이던 초안도 보존되는지 확인했다.
- 1440px PC는 카드 3열, 390px 모바일은 단일 열이며 페이지와 상세 모달에 가로 넘침이 없었다. 시각 검증 후 임시 뷰포트를 해제했다.
- 최종 JS와 로컬 서버 구문 검사, HTML/이미지 HTTP 200, git diff --check 통과. 독립 정적 목업이므로 기존 Next.js 빌드와 API 테스트는 재실행하지 않았다.
- 목업 검토용 입력값은 초기화했다. 화면 저장에 쓰던 임시 입력 대기 프로세스는 종료했다. 검토용 서버만 유지한다.
