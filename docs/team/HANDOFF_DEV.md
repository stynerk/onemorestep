## #84 Router 도메인 근거 판정 · 서비스PM 검토

- 기준은 PR #85 병합 `c94ce30`의 엔진(`7c41370`)이다. 규칙에서 도메인이 미확인이고 판정이 애매할 때만 Router가 기존 검색 결과를 읽는다. 근거가 확인된 기관 소유 응답을 국가·제휴·구매 판정에 반영한다. 공개 데모는 저장 응답을 재생한다.
- 기존 검색 응답 170건을 재생했다. 신규 Router 호출은 평가 10건, SaaS 2건에 각 1회였다. HTTP 200 및 인용·URL 검증은 각 12/12였고 재시도와 신규 검색은 0건이었다.
- 결과를 본 뒤 평가 판정 52/70 및 넘길 곳 52/67이 유지됐다. SaaS는 판정 8/10→10/10, 넘길 곳 10/10이었다. 의료기기 저장 판정과 넘길 곳 모두 30/30이었다. 평가 E09·E63은 출처에서 기관 동일성을 확인할 수 없어 애매를 유지했다.
- 거짓 유효와 유효→무효 0건, 사칭 애매, 가상 기관 무효, 공개 메일 403을 확인했다. 공개 빌드에서 I05 국가 확인과 I06 구매 회신 뒤에도 근거가 유지되고 유효로 이어졌다. 자동 테스트 92/92, lint, 타입 검사, 공개 빌드, 브라우저 E2E 34/34를 확인했다.
- Tony 승인과 QA 결과를 받아 11-23 12:00 재동결에 반영한다. 시한까지 조건을 못 채우면 현재 main 엔진으로 측정한다. 새 블라인드 세트는 열지 않았고, #86은 별도 인계 이후 시작한다.
