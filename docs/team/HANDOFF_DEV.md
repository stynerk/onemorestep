- 재동결 엔진 기준은 PR #87 병합 `1bde1c5`다. 판정 서비스와 규칙은 그대로 사용한다. 문의함의 애매 목록에서 답하면 확인 항목만 반영해 남은 단계와 기존 추천을 적용한다. 사칭을 정상으로 진행하는 답은 해당 리드에만 적용한다.

- Router 질문 템플릿 5개를 기록했다. 호출 5/5, 검증·재생 5/5, 재시도 0이며 실제 기관명과 문의 본문을 보내지 않았다. 공개 시연과 후속 질문은 기록을 재생하고 문구가 없으면 유형별 기본 질문을 쓴다.
- 공개 API에서 답변 전 의료기기 판정·인계 30/30, SaaS 10/10, 외부 호출 0, 메일 403을 확인했다. Playwright는 실제 L29의 딜러 추천과 시험용 동일 도메인 쌍의 기억 복원·초기화를 검증했다.
