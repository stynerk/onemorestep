## 데이터·저장 계약

- `(빈칸)` 기관명은 빈 문자열, 카자흐스탄 지역 미지정 괄호는 주석으로 정규화했다. 나머지 원문 필드·순서를 보존하며 L06이 마지막이다. 이름·전화는 명백한 가상 플레이스홀더다.
- 평가 정답은 evaluation/ground-truth.json에만 있고 런타임 seed·store 입력에서 읽지 않는다. 초기 판정은 null, 업무 상태는 new다.
- 가상 전달 내역은 원문 딜러별 결과 합계와 일치하며 기관은 리드와 겹치지 않는다. 기존 거래 관계 두 건은 별도 데이터다. 딜러 상품 범위는 시연 세 종류 모두라는 가정이다.
- localStorage는 단일 사용자 브라우저 단위다. 복원·중복 차단·시연 초기화 API, 저장 실패 결과를 제공한다. 손상 데이터는 명시적 초기화 전 덮어쓰지 않고 저장 실패 시 메모리도 부분 변경하지 않는다. SSR import는 window에 접근하지 않는다.
- 상태를 결정하는 UI·서버 연동은 #31/#25가 맡는다. SMTP 서버와 브라우저 저장소는 공유되지 않으므로 검증된 전송 결과를 이벤트로 반영해야 한다. 인증 정보·실제 수신 주소는 저장하지 않는다.
