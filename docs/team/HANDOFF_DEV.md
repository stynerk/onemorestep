- 판정 엔진 `c1f7c46`의 판정·평가 서비스·기관 정책·저장 근거·전달 함수 5개 파일은 바이트가 같다. 추천·재배정은 기존 계산에 선택한 업종의 정책값을 넘긴다. 기존 170건 오프라인 재생에서 의료기기 시연·평가의 판정과 전달 결과가 건별로 일치했다.

- 승인 정본 `docs/product/INDUSTRY2_DATA.md` 인계 대기다. 공개 버튼은 준비 중으로 표시하고, 테스트 입력은 제품 설정에 등록하지 않았다. 새 블라인드 30건은 별도 인계 대상이다.
