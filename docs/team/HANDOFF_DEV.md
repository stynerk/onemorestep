## #135 대규모 보조 평가

- HJ가 확인한 Gemini 답안 CSV를 바탕화면 원본 그대로 보존했다. SHA-256이 일치하고 선별 정답 1,000건을 확인했다. 답안의 넘길 곳이 빈 무효 113건은 채점에서 없음으로 읽었다.
- 동결 main ca0cf6e의 엔진으로 1,000건을 평가했다. Liner 검색 450회, Router 1,186회 모두 HTTP 200이며 검색 응답을 1,526회 재사용했다. 오프라인 재생으로 1,000건의 예측 해시가 일치했다.
- Gemini 라벨 기준 선별 579/1,000(57.9%), 넘길 곳 528/1,000(52.8%), 유효→무효 104건, 거짓 유효 8건이다. 선별 불일치 421건 가운데 268건이 애매로 갔다. 유효→무효 104건 중 100건은 Gemini가 유효로 표시한 가상 기관이다.
- 보고서에 유형·언어별 일치율, 선별·인계 전이표, 생성 의도와 Gemini 라벨의 교차표를 실었다. 응답과 유형·언어 매핑은 본 폴더의 로컬 백업 .cache/frozen-evaluations/issue-135-x/에 있다.
- HJ가 정한 범위에 따라 사람 정답 100건 대조는 제외했다. 사람 정답 블라인드 17/30을 대표 수치로 유지한다. Tony는 검토 PR #139에서 README 보조 문단을 확인한 뒤 기획서 반영 여부를 결정한다. 공개·제출은 HJ 담당이다.
