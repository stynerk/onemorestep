# 미리내 (onemorestep)

미리내는 딜러망을 운영하는 제조사의 리드를 판정하고, 넘길 곳과 적합한 딜러를 추천하는 세일즈 에이전트입니다. 제1회 라이너 해커톤 .EXE-THON 출품작입니다.

## 공개 시연

[미리내 공개 시연](https://onemorestep-wheat.vercel.app/)에서 **판정 시작**을 누르면 가상 리드 30건이 유효 8건, 애매 6건, 국가 확인 3건, 제휴 확인 2건, 무효 11건으로 분류됩니다. 목록과 카드에서 판정 근거와 넘길 곳을 확인할 수 있습니다.

공개 문의함은 저장된 검색 근거로 판정하고 메일 발송을 차단합니다. 결정·회신·재배정 기록은 이 브라우저에 저장되며 **시연 초기화**로 지울 수 있습니다.

## 심사위원 로컬 실시간 실행

Node.js 24에서 저장소 루트의 의존성을 설치합니다.

```powershell
npm ci
```

`.env.example`을 복사해 `.env.local`을 만듭니다. 이미 있는 로컬 환경 파일은 그대로 열어 편집합니다.

```dotenv
LINER_MODE=live
LINER_API_KEY=여기에_본인_Liner_API_키
```

```powershell
npm run dev
```

[로컬 문의함](http://127.0.0.1:3000)에서 **판정 시작**을 누르면 Liner로 기관을 조사합니다. 환경 파일을 편집한 뒤에는 서버를 다시 시작합니다. 키 없이 실행하거나 `LINER_MODE=sample`을 지정하면 저장된 근거로 시연할 수 있습니다. 메일 검증이 필요하면 [로컬 테스트 수신함 설정](docs/tech/FORWARDING_IMPLEMENTATION.md#테스트-수신함-메일-25)을 따릅니다.

**장면 6 재배정.** 저장 모드에서 L23의 제휴 회신을 **구매 문의 확인**으로 기록하고 추천 순위가 V MedSource, U Health Supply 순인지 확인합니다. L03을 V MedSource에 배정한 뒤 **기한 경과 시뮬레이션**을 누르고 **재배정 승인**을 누르면 U Health Supply에 배정됩니다. L23에서 U Health Supply가 1위로 바뀌고 V MedSource가 2위로 내려간 이유를 확인할 수 있습니다.

## Liner를 쓰는 곳

미리내는 Liner Web Search로 리드마다 **기관명 + 국가**, **기관명 + 업종**을 검색합니다. 검색 결과로 소속 기관과 소재지, 공식 도메인을 확인합니다. 리드의 이메일과 공식 도메인을 대조해 사칭 의심도 표시합니다. 담당자는 결정 카드에서 검색 근거와 넘길 곳을 확인한 뒤 승인할 수 있습니다.

## 측정 결과

| 세트 | 판정 환경 | 판정 일치율 |
| --- | --- | ---: |
| 시연 30건 | 공개 시연과 같은 저장 근거 | 30/30 (100%) |
| 시연 30건 | 실제 Liner 검색 | 27/30 (90.0%) |
| 평가 70건 | 동일한 실제 검색 응답에 정정 정답 대조 | 33/70 (47.1%) |
| 평가 70건 | 같은 응답에 원본 정답 대조 | 23/70 (32.9%) |

확정 엔진 `8d4f0ac`을 2026년 11월 20일에 측정했습니다. 11월 21일에 가상 기관 11건의 정답을 무효로 정정하고 기존 응답으로 재채점했습니다. 측정 조건, 넘길 곳 일치율, 혼동행렬은 [최종 평가 기록](docs/qa/FINAL_EVALUATION_2026-11-20.md)에 있습니다.

## 한계

- 평가에서 실제 기관의 유효 리드 15건 중 12건은 공식 페이지를 확인하지 못해 애매로 권역 세일즈팀에 이관했습니다. 3건은 검색 결과에서 기관 일치 근거를 찾지 못해 무효로 분류했습니다.
- 기관 확인이 필요한 리드의 실시간 검색에 실패하면 화면에 이유를 표시하고 담당자 확인으로 넘깁니다.
- 공개 시연은 가상 데이터와 저장된 검색 근거를 사용합니다. 여러 담당자가 공유하는 업무 기록과 실제 메일 발송은 데모에서 지원하지 않습니다.
