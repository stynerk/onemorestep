# 미리내 Playwright 검증

Node.js 24에서 검사한다. 기준은 [QA 체크리스트](../../docs/qa/CHECKLIST.md)다. 항목 ID는 테스트 이름에 들어 있다.

```powershell
npm ci
npx playwright install chromium
npm run test:e2e
```

기본 실행은 로컬 저장 모드와 격리된 공개 모드 서버를 띄운다. 외부 Liner 호출을 막고, 메일 요청은 테스트가 가로채 발송 응답을 모의한다. 모의가 빠진 요청도 테스트 서버에서 막힌다. 공개 모드에서는 앱의 403 응답을 확인한다. 브라우저는 1440×900으로 실행하며 화면 캡처는 `test-results/scenes/`에 남는다.

## Liner 기록 재생

공개 기관을 묻는 시연용 L03을 브라우저에서 판정한다. 새 기록을 만들 때는 서버용 Liner 키가 환경이나 로컬 `.env.local`에 필요하다. 같은 기록을 재생할 때는 키 없이 실행할 수 있다.

```powershell
npm run test:e2e:live
npm run test:e2e:live
```

빈 기록 폴더에서 정상 응답을 받아 한 번 실행하면 Liner에 두 번 요청하고, 두 번째 실행은 두 응답을 재생한다. 콘솔에서 실제·재생·차단 횟수를 확인한다. 키 없이 기록이 없거나 기록 읽기에 실패하면 테스트가 실패한다.

캐시는 시연 입력·시연 정답·요청 본문·API 버전이 모두 같을 때 적중한다. 지문 변경을 검증하려면 시연 정답 파일을 `tests/fixtures/recorded/` 아래에 복사하고 `MIRINAE_E2E_TRUTH_PATH`로 그 사본을 선택한다. 같은 파일로 한 번 실행해 재생을 확인한 뒤 사본의 끝에 공백 한 글자를 추가하면 다음 실행이 다시 기록한다. `MIRINAE_E2E_RECORD_DIR`로 같은 폴더 아래의 별도 기록 디렉터리를 선택할 수 있다.

기록에는 날짜, API 버전, 입력 지문과 허용된 공식 기관 도메인·소재지·업종 근거만 남는다. 녹화 대신 화면 캡처를 저장한다. 기록과 캡처는 Git 추적에서 제외한다. 검색 응답의 정규화된 재생으로 판정 경로를 검증하며 실시간 분류의 정확도는 별도로 측정한다.
